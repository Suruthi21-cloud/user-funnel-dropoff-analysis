# User Funnel Drop-off Analysis

## Project Overview
This project analyzes a user conversion funnel using Excel to identify conversion rates and drop-off percentages at each stage of the user journey. An interactive dashboard was created to visualize key metrics and provide business insights.

## Objectives
- Calculate user count at each funnel stage.
- Measure conversion and drop-off rates.
- Identify the stage with the highest user drop-off.
- Provide business recommendations to improve conversions.

## Tools Used
- Microsoft Excel
- Pivot Table
- Excel Charts
- Dashboard Design

## Dashboard Features
- KPI Cards
- Funnel/Bar Chart
- Funnel Analysis Table
- Key Insights
- Business Recommendation

## Key Findings
- Total Visitors: **200**
- Completed Purchases: **44**
- Overall Conversion Rate: **22.00%**
- Highest Drop-off: **45.83%** (Details Filled → Email Verified)

## Recommendation
Improve the email verification process by reducing friction and providing faster or alternative verification methods such as OTP or social login to improve the overall conversion rate.
